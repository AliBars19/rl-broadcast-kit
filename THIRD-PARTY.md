# Third-party material

## Fonts

The fonts in `fonts/` are bundled so the overlays work offline. All three families are licensed under the SIL Open Font License, Version 1.1. The full licence text for each family, fetched from the upstream Google Fonts repository, sits next to the font files.

| Family | Files | Copyright holder | Licence text |
|---|---|---|---|
| Chakra Petch | `ChakraPetch-500.woff2`, `-600`, `-700` | The Chakra Petch Project Authors | `fonts/OFL-ChakraPetch.txt` |
| IBM Plex Mono | `IBMPlexMono-400.woff2`, `-500`, `-600` | IBM Corp. (Reserved Font Name "Plex") | `fonts/OFL-IBMPlexMono.txt` |
| IBM Plex Sans | `IBMPlexSans-var.woff2` | IBM Corp. (Reserved Font Name "Plex") | `fonts/OFL-IBMPlexSans.txt` |

Upstream sources: <https://github.com/google/fonts/tree/main/ofl/chakrapetch>, `.../ibmplexmono` and `.../ibmplexsans`.

The `.woff2` files are web-format builds of these families. Keep the licence files with them if you redistribute the fonts.

## Gradle wrapper

`tools/phonecam/android/gradle/wrapper/gradle-wrapper.jar` and the `gradlew` and `gradlew.bat` scripts come from the Gradle build tool (Gradle 9.0.0 wrapper) and are licensed under the Apache License, Version 2.0, copyright Gradle Inc. and the Gradle authors. Licence text: <https://www.apache.org/licenses/LICENSE-2.0>. They are included so `./gradlew` works without installing Gradle. Building the phone app downloads Gradle, the Android Gradle Plugin, Kotlin and JUnit (EPL-1.0) from their own repositories; none of that is bundled here, and the Android SDK is installed by you.

## Sound effects

The five WAV files in `tools/clips/sfx/` are generated by `tools/clips/sfx/make_sfx.sh` from ffmpeg signal generators and filters. They contain no sampled or third-party audio.

## Dependencies

None required. The Node and Python code uses only the standard libraries. External programs used when you run the tools (not bundled): OBS Studio, ffmpeg, Google Chrome, and for PhoneCam adb and (optionally) scrcpy. numpy is an optional dependency of `tools/clips/make_crowd_stem.py` and `tools/phonecam/sync_audio.py`.
